# 4. Sécurité et périmètre

Le dépôt distingue des fichiers sous BUSL-1.1 et d’autres sous MIT, avec un en-tête SPDX par fichier. Toute réutilisation doit respecter la licence réellement attachée au fichier, et la documentation ne vaut pas autorisation juridique.

Les risques à examiner comprennent les deltas non réglés, les hooks malveillants, les arrondis de prix, les tokens non standards, les permissions de PoolManager et les interactions réentrantes. Le dépôt contient des dossiers test et des workflows, mais aucun test, build ou déploiement n’a été exécuté dans ce parcours.

Ce parcours reste documentaire : il explique la structure visible de v4-core sans déclarer de comportement validé en exécution.
